# Hangeul Miniature

플랫폼 구분 없는 미니어처 이미지·영상 프롬프트 제작기입니다. 외부 API나 API 키 없이 로컬에서 규칙 기반으로 생성합니다. 자유 입력은 자동 번역하지 않고 원문 그대로 포함하며, 공통 촬영 지시는 영어로 출력합니다.

미니어처 캐릭터, 스타일 혼합, 실제 축척, 재질, 촬영 설정을 조합하여 프롬프트를 작성하는 Streamlit 앱입니다. 이미지·영상 자체를 생성하는 프로그램은 아닙니다.

저장소: [rgb0rgb/hangeul-miniature](https://github.com/rgb0rgb/hangeul-miniature)

## 설치 및 실행

Python 3.10 이상이 필요합니다. Python 3.12와 Streamlit 1.55.0 환경에서 테스트했습니다.

```bash
git clone https://github.com/rgb0rgb/hangeul-miniature.git
cd hangeul-miniature
```

### Windows

Windows에서 `run.bat`을 실행합니다. 최초 실행은 Python과 패키지 다운로드 연결이 필요합니다. 설치 이후에는 `run_no_install.bat`으로 실행할 수 있습니다.

### Linux / macOS

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

기본 접속 주소는 `http://localhost:8501`입니다. 포트가 사용 중이면 `python -m streamlit run app.py --server.port 8519`처럼 다른 포트를 지정할 수 있습니다.

## 구성

- 장면과 주 피사체 필수 입력, 이미지·영상 출력, 화면 비율 선택
- 실제 축척, 재질, 마감, 표면 상태, 디테일 밀도, 크기 기준물
- 렌즈, 초점, 각도, 구도, 조명, 배경 설정
- 영상 전용 카메라 이동, 길이, 피사체 동작, 시간적 일관성 지시
- 전체 프롬프트·본문·제외 조건 구분, 코드 블록의 기본 복사 버튼, TXT 다운로드
- 캐릭터별 이름·외형·표정·포즈·소지품·상호 위치 설정 (최대 6명)
- 지브리, 월레스와 그로밋, 슈퍼 마리오, 어벤져스, 픽사, 레고, 산리오, 포켓몬, 실바니안 패밀리, 한국 동화 마을 스타일
- 주 스타일과 보조 스타일의 포인트 혼합, 캐릭터/배경 분리, 형태 융합
- 형태·색감·의상·배경·분위기로 정의하는 사용자 스타일 추가 및 로컬 영구 저장
- 4개 장면 예시와 스타일 선택은 별개이며, 장면은 자유 입력 가능
- 현재 작업 저장·불러오기: 스타일 정의와 캐릭터를 함께 보존하는 JSON v4, 기존 v2·v3 파일도 읽기 가능

설정을 바꾸면 이전 결과에 변경 알림이 표시됩니다. TXT는 마지막 생성 결과이며, '현재 작업 저장'은 현재 입력을 저장합니다. 필수 입력이 완성되어야 작업을 저장할 수 있습니다. 새 작업이나 장면 프리셋 적용은 현재 입력을 교체합니다.

영상 동작은 기본적으로 현재 장면에 적힌 사건 순서를 따릅니다. '동작 직접 지정'을 선택한 경우에만 별도 동작을 사용하며, 해당 동작은 작성 당시 장면·주 피사체에 연결됩니다. 장면이나 주 피사체를 편집하면 별도 동작이 초기화됩니다. 촬영·스타일 설정 변경은 동작을 초기화하지 않습니다. 기존 v2·v3 파일의 동작 텍스트는 보존하되 자동 적용하지 않으며, 직접 지정 모드로 전환해야 현재 장면에 연결됩니다. 외부에서 작업 내용을 수정하여 연결이 어긋난 경우에도 생성기는 이전 동작을 제외합니다.

사용자 스타일은 `data/styles`에 저장되어 재실행해도 유지됩니다. 같은 스타일을 반복 저장해도 중복 파일을 만들지 않습니다. 작업 파일에 포함된 사용자 스타일은 별도 설치 없이 해당 작업에서 선택·사용할 수 있습니다. 테스트용 저장 위치는 `MINI1_STYLE_DIR` 환경변수로 지정할 수 있습니다.

스타일 이름은 시각적 참고이며 인기도 순위를 뜻하지 않습니다. 프롬프트에서는 명시한 캐릭터 정체성, 장면, 재질·축척·촬영 설정을 스타일보다 우선하도록 지시합니다. 주 스타일은 형태 기준을 유지하며 보조 스타일 적용 범위는 혼합 방식에 따라 달라집니다. 혼합 백분율은 모델 전용 가중치 문법이 아닌 시각적 강조 지시입니다. 캐릭터 이름을 직접 입력할 수 있으며 스타일 선택만으로 원작 등장인물을 자동 추가하지 않습니다.

입력 선택값, 길이, 파일 구조는 검증하지만 자유 문장 사이의 의미 충돌까지 자동 검출하지는 않습니다. 축척과 영상 길이는 생성 모델에 전달할 지시이며 실제 이미지·영상 생성 및 준수 여부 검증은 이 앱의 기능이 아닙니다.

## 검증

```bash
python -m unittest discover -s tests -v
```

23개 테스트로 입력 검증, 스타일 혼합 270개 경우, 캐릭터 보존, 사용자 스타일 저장, 작업 파일 호환성과 화면 동작을 확인합니다. 철도 프리셋에서 우주선 장면으로 변경할 때 이전 기관차 동작이 섞이지 않는 회귀 테스트를 포함합니다. 이 테스트는 프로그램과 프롬프트 구성 검증이며, 외부 이미지·영상 모델의 결과 품질 검증은 아닙니다.

## 파일 구성

```text
app.py                 Streamlit 화면과 입력 상태 관리
modules/templates.py   설정, 장면 예시, 작업 파일 저장·복원
modules/styles.py      기본 스타일과 사용자 스타일 저장
modules/compiler.py    프롬프트 생성과 동작 연결 검사
tests/                 자동 검증
requirements.txt       실행 의존성
run.bat                Windows 설치·실행
run_no_install.bat     Windows 재실행
```

가상환경, 캐시, 비밀 설정 파일 및 `data/`의 개인 스타일 파일은 Git 추적 대상에서 제외합니다.
